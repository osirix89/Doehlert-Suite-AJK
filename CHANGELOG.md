# Changelog

## [0.1.0] - 2026-11-12

First public release prepared for GitHub.

- Five-tab desktop interface for three-factor Doehlert design generation and analysis.
- Quadratic response-surface fitting, ANOVA, coefficient inference, and diagnostics.
- Modular experimental-domain, constrained-optimization, multiple-response, and publication-comparison components.
- Integrated audit utility and automated tests.
- CSV import, example datasets, and report/table export workflows.
- English is now the default interface language; Spanish can be selected from the Language menu.
- English and Spanish user manuals, technical documentation, quick-start guides, and audit guides.
- GNU GPL v3.0-only license.

### Release verification

- Python compilation checks.
- Automated unit tests (see the release validation record).
- GUI startup and workflows should also be checked on the target operating systems before production use.
