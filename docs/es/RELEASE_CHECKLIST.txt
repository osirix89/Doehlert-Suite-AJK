Verificaciones locales realizadas para este paquete

- Comprobación de importación de todos los CSV de ejemplo y validación

Antes de publicar
- Crear un repositorio público de GitHub llamado Doehlert-Suite.
- Subir el contenido del repositorio (no dejar el ZIP como único artefacto del repositorio).
- Confirmar que el flujo de Actions finalice correctamente en GitHub.
- Crear y subir la etiqueta v0.1.0.
- Adjuntar un ZIP del código fuente al Release de GitHub si se desea.

Esta lista no afirma una validación exhaustiva de todos los casos estadísticos, sistemas operativos o flujos gráficos.
